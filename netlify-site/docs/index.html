Introduction to ArkCase

ArkCase is the leading open source case management and IT modernization platform, designed to accelerate your case management initiatives and reduce implementation costs.

📘 About This Documentation

This documentation provides an overview of ArkCase features and architecture. For complete documentation, visit the official ArkCase developer portal.

What is ArkCase?

ArkCase is an enterprise-grade case management system that provides:

  • Case Management - Track and manage cases through their complete lifecycle
  • Document Management - Integrated with Alfresco for robust ECM capabilities
  • Workflow Automation - Activiti-powered business process management
  • Search - Apache Solr integration for powerful search capabilities
  • Reporting - Pentaho integration for analytics and reporting
  • Security - Enterprise authentication (LDAP, SAML, OAuth2, Kerberos)

Use Cases

ArkCase is suitable for various case management scenarios:

📋 FOIA Processing

Freedom of Information Act request management and processing

🔍 Investigations

Case-based investigation management and tracking

📝 Complaints

Complaint intake, tracking, and resolution

⚖️ Legal

Legal case management and document tracking

Installation

ArkCase can be installed in several ways depending on your needs.

Prerequisites

  • At least 16 GB RAM
  • At least 50 GB disk space
  • Java 8 (AdoptOpenJDK recommended)
  • Maven 3.5+
  • Node.js and Yarn
  • VirtualBox and Vagrant (for VM setup)

Option 1: Pre-built Virtual Machine

The easiest way to get started is with the pre-built VM:

# Clone the arkcase-ce repository
git clone https://github.com/ArkCase/arkcase-ce.git
cd arkcase-ce

# Follow the instructions in the README
# to download and run the pre-built VM

Option 2: Build from Source

For development or customization:

# Clone the repository
git clone https://github.com/ArkCase/ArkCase.git
cd ArkCase

# Build with Maven (skip integration tests)
mvn -DskipITs clean install

# The WAR file will be at:
# acm-standard-applications/arkcase/target/arkcase-{version}.war

⚠️ Backend Services Required

ArkCase requires several backend services: MySQL, Solr, ActiveMQ, Alfresco, and Pentaho. These are included in the pre-built VM or must be configured separately.

Configuration

ArkCase uses a configuration folder that must be set up before running.

Configuration Folder

Clone the configuration repository:

git clone https://github.com/ArkCase/.arkcase.git ~/.arkcase

Config Server

Starting with version 3.3.1, ArkCase requires a Spring Cloud Config Server:

# Download config server from:
# https://github.com/ArkCase/acm-config-server/releases

# Start the config server
java -jar config-server-{version}.jar

# Default port is 9999

Tomcat Configuration

Configure Tomcat 9 with the TLS connector and native libraries as described in the main README.

First Steps

After installation, here's how to get started with ArkCase.

Logging In

Access ArkCase at https://arkcase-ce.local/arkcase (or your configured URL).

Default admin credentials:

  • Username: arkcase-admin@arkcase.org
  • Password: @rKc@3e

Creating Your First Case

  1. Navigate to Cases in the sidebar
  2. Click "New Case"
  3. Fill in the required fields
  4. Assign to a user or group
  5. Submit the case

Cases

Cases are the core entity in ArkCase, representing a matter that needs to be tracked and managed.

Case Lifecycle

Cases in ArkCase follow a configurable lifecycle:

  1. Draft - Initial creation, not yet submitted
  2. Active - Case is being worked on
  3. In Review - Under review by supervisor
  4. Approved - Case work approved
  5. Closed - Case completed

Case Components

Each case can contain:

  • Documents and attachments
  • Tasks and assignments
  • Notes and comments
  • People and organizations
  • Timeline and history

Tasks

Tasks are work items that need to be completed, often associated with cases.

Task Types

  • Manual Tasks - Created by users
  • Workflow Tasks - Generated by business processes
  • Approval Tasks - Require approval decisions

Documents

ArkCase provides robust document management through Alfresco integration.

Features

  • Upload and organize documents
  • Version control
  • Document preview
  • Full-text search
  • Access control

Workflows

ArkCase uses Activiti BPM for workflow automation.

Capabilities

  • Visual process modeling
  • Automatic task assignment
  • Parallel and sequential workflows
  • Timer events
  • Business rules integration

Integrations

ArkCase supports various integrations:

  • LDAP - Directory services integration
  • SAML - Single sign-on
  • OAuth2 - Modern authentication
  • Kerberos - Windows authentication
  • Microsoft Exchange - Email integration
  • CMIS - Content management interoperability

REST API

ArkCase provides a comprehensive REST API for integration and automation.

API Endpoint Examples

# Get all cases
GET /api/v1/plugin/casefile

# Create a new case
POST /api/v1/plugin/casefile

# Get case by ID
GET /api/v1/plugin/casefile/{id}

# Update case
PUT /api/v1/plugin/casefile/{id}

# Search
GET /api/v1/plugin/search?q={query}

📚 API Documentation

ArkCase includes Swagger UI for API exploration. Access it at /swagger-ui.html when running the application.

Authentication

ArkCase supports multiple authentication methods.

Supported Methods

  • LDAP - Standard LDAP/AD authentication
  • SAML 2.0 - SSO with identity providers
  • OAuth2/OIDC - Modern token-based auth
  • Kerberos - Windows integrated auth

API Authentication

API requests can be authenticated using:

  • Session cookies (for browser-based access)
  • Bearer tokens (for API access)
  • Basic authentication (for simple integrations)
