Architecture

ArkCase is built on modern, enterprise-grade technologies:

  • Backend: Spring Framework 5.x, Spring Security, Spring MVC
  • Frontend: AngularJS with modular architecture
  • Database: MySQL, PostgreSQL, MariaDB, SQL Server support
  • Search: Apache Solr
  • Content Management: Alfresco
  • Messaging: Apache ActiveMQ
  • Workflow: Activiti BPM
  • Reporting: Pentaho

Get Started

⚠️ Important Note

This is a static demo page. ArkCase is a full Java enterprise application that requires:

  • Java 8+ with Tomcat 9 application server
  • Backend services: MySQL, Solr, ActiveMQ, Alfresco, Pentaho
  • At least 16 GB RAM and 50 GB disk space

Quick Start Options

Option 1: Pre-built Virtual Machine

Download and run a pre-built ArkCase VM:

Download VM

Option 2: Developer Setup

Build and run ArkCase from source:

# Clone the repository
git clone https://github.com/ArkCase/ArkCase.git
cd ArkCase

# Build with Maven
mvn -DskipITs clean install

# Follow the full setup guide in README.md
